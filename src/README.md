### Student Code (src/)

Teams should place all project-specific Python code in the `src/` folder. Keep modules organized by feature and use clear names. A minimal structure example:

```
src/
├── __init__.py
├── controllers/
│   ├── __init__.py
│   └── lane_follower.py
└── sensors/
   ├── __init__.py
   └── ultrasonic.py
```
